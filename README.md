# Pear — демо мессенджера

Интерактивный адаптивный прототип: переключение чатов, поиск по именам, фильтры, избранное, создание демочата, отправка и эмодзи. Сообщения и созданные чаты сохраняются в localStorage браузера на этом устройстве. Собеседники, статусы и переписка демонстрационные — сообщения не доставляются другим людям. Для настоящего мессенджера нужны сервер, авторизация, база данных, защита и транспорт сообщений.

## Запуск
Откройте `index.html` в браузере, сохраняя соседние файлы и папку `assets`.

## Vercel
Загрузите содержимое папки в GitHub и импортируйте репозиторий в Vercel. Выберите Framework Preset: Other; Build Command и Output Directory оставьте по умолчанию. Пакеты, сервер и ключи не нужны.
